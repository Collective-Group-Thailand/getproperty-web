# CLAUDE.md — getproperty-web

**getproperty — บิลทำเอง เก็บเงินเอง ถูกกฎหมาย** · operated by Collective Group (Thailand) · a new product (no legacy; `getpack-web` is a conventions reference only, D-003)
This repository is the **single Next.js 16 application** of getproperty. It serves four zones from one codebase and one deployment:
- **owner zone** (`OWNER_HOST`) — the landlord's console: morning dashboard, properties & rooms, leases & deposits, billing cycles & bills, payments & arrears, meters & loss, settings, subscription
- **tenant zone** (`TENANT_HOST`) — LINE Mini App (LIFF) and mobile web for tenants: bills & QR, receipts, usage, repairs, announcements, parcels, lease documents, move-out notice
- **staff zone** (`STAFF_HOST`) — mobile-first PWA for caretakers / technicians / installers: reading rounds with camera + OCR, inspections, device provisioning, tickets, parcels
- **admin zone** (`ADMIN_HOST`) — platform back-office for Collective Group staff: orgs & subscriptions, tariffs, device fleet & OTA, support grants, DSR, audit

The backend is a separate repository (`getproperty-api`, NestJS). This app never talks to a database and never computes money, tariffs, billing dates or compliance — it renders what the API returns.

## Hard rules
- API types come only from `src/lib/api/schema.d.ts` generated by `pnpm gen:api` from the backend contract. Never hand-write response types. If an endpoint you need does not exist, write it into `docs/contract-requests.md` (method, path, purpose, fields) and use an MSW mock marked `// CONTRACT-REQUEST` — never invent it silently.
- Tokens live only in httpOnly cookies set by this app's server; browser code calls the zone BFF (`/bff/*`), server code calls `API_INTERNAL_URL`. No tokens in localStorage or JS-readable cookies. The LIFF id token is exchanged once through the tenant BFF and never kept in JS.
- Zone isolation: owner code must not import `src/features/tenant|staff|admin/**` and so on (ESLint boundaries enforce it). Shared code goes to `src/ui`, `src/features/shared`, `src/lib`, `src/domain`, `src/i18n`.
- UI primitives come from `src/ui` only; extend `src/ui` instead of styling locally. All copy through `src/i18n` (th default, en; tenant zone adds my/km/lo/zh in R2). Status labels/tones/icons only from `src/domain/status`.
- Money is a decimal string from the API; format with `formatTHB`, never do arithmetic on it. Meter quantities are decimal strings; format with `formatUnits`. Dates from the API are rendered in `Asia/Bangkok` (Buddhist era for tenants and owners, ISO in exports).
- Compliance refusals from the API (`compliance.*` with `legalRef`) are shown with their legal reference and never worked around in the UI (no client-side "override").
- Values that decisions mark as configurable are read from the API (settings), never hard-coded in the UI.
- Never copy third-party designs, templates, text or assets (competitor apps included). Brand = getproperty tokens.
- Plan Mode first for each deliverable; wait for approval. Small vertical slices, Conventional Commits, green CI per slice. When ambiguous: record the assumption in `docs/PROGRESS.md` and take the most conservative option.
